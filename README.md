# Samuel Login Web

Tela de login simples desenvolvida em Angular a partir do modelo fornecido.

## Funcionalidades

- Campos de e-mail e senha com validação.
- Envio do formulário para o componente TypeScript.
- Impressão dos dados no console do navegador ao clicar em **Entrar**.
- Opções de **Esqueci a senha** e **Criar conta**.
- Layout responsivo para desktop e celular.

## Executar localmente

Instale as dependências e inicie o servidor de desenvolvimento:

```bash
npm install
npm start
```

Abra [http://localhost:4200](http://localhost:4200) no navegador.

Para conferir os dados enviados, abra as ferramentas do desenvolvedor do navegador e acesse a aba **Console**.

## Testes e build

```bash
npm test -- --watch=false
npm run build
```
